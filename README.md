# GX-Extensions
A collection of GX Extensions for GameMaker GX.Games target. 

These extensions have been tested thoroughly to ensure that they work on Chromium-based browsers and Firefox.

# How to install

1. Head over to [releases](https://github.com/tabularelf/GX-Extensions/releases) and download the desired extensions yymps.
2. In GameMaker, goto Tools -> Import Local Package and import.
3. Follow the relevant additional steps per extension, if any.

# Extensions

## GX Cut

GX Cut is a simple fade removal extension. GX.Games target by default does a gradual fade-in whenever the game starts. This extension simply removes it entirely. 

### Additional install steps

None. This extension is purely plug-n-play!

## GX Recommence

GX Recommence is a simple pause removal extension. GX.Games target by default applies a pause screen whenever the current game tab loses focus. This extension simply removes it by overriding the pause functionality.

### Additional install steps

None. This extension is purely plug-n-play!
